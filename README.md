## 系统要求

建议在 Windows XP 以上系统运行。
最低配置：

- **系统**：Windows 2000
- **CPU**: Intel (R) Pentium
- **RAM**: 128 MB
- **可用硬盘空间**：8 MB

## 编译

不建议在 Windows 11 上进行编译。
本程序使用 VB Sirk Mini 进行编写，所以请用相同的应用编译
